# GoGo Company — backlink & referral outreach queue

Last researched: 2026-11-26  
Scope: earned editorial references for the GoGo Company portfolio. This is a prospecting and copy-preparation document; no third-party forms or emails have been submitted.

## Rules

- Prefer free editorial review and relevant audiences. Never pay for a followed link, placement, anchor text or ranking promise.
- Do not require reciprocal links. Do not promise a backlink to a directory in exchange for listing.
- Read the current submission rules before every submission; policies and URLs can change.
- Submit only products that work on the published URL and for which GoGo has distribution rights. Use GoGo's public contact channel for any reviewer follow-up.
- Measure accepted listings, referring domains and referral sessions. A listing is not proof of SEO benefit, and a nofollow/UGC link can still send useful players.
- Do not submit the same generic pitch to unrelated communities. Participate in communities and follow their self-promotion rules.

### Do not use without further rights/policy review

- [Tabatu](https://tabatu.com/submit-game) requires an open-source licence or a licence allowing embedding and redistribution. Do not submit either game until the game and all included art/audio/third-party assets have clear compatible rights.
- [Diario Games](https://diariogames.com/submit) focuses on daily art/culture games; these GoGo games are not a clear editorial fit.
- [itch.io game jams](https://itch.io/docs/creators/quality-guidelines) are not generic promotion directories. Do not submit to unrelated jams just to obtain exposure or links.

## Editorial/community participation ideas

- For r/WebGames and r/playmygame: share one game at a time only after reading each community's current self-promotion rules. Ask for specific feedback on puzzle readability, difficulty or mobile controls; do not ask for upvotes.
- For indie game Discord servers: participate first, use a dedicated showcase/feedback channel if allowed, and post a short gameplay clip plus the official URL.
- For game-jam communities: participate only when the game genuinely meets the theme and entry rules. Never join unrelated jams just to promote a link.
- For Show HN: reserve for a substantive build/engineering story (e.g. how an original 1,000-level puzzle PWA was designed), not a generic “please play” post.
