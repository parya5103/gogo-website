Arrow Out! — a tap-away arrow puzzle

Arrow Out! is a path-planning puzzle. Tap an arrow only when its route to the edge of the board is clear; another arrow in the corridor blocks it. Plan the removal order, clear every arrow and work through 1,000 levels. The game also includes daily challenges, hints, undo and board controls for larger puzzles.

Read the complete Arrow Out! tap-away puzzle guide for the rules, then use the Arrow Out! strategy guide to plan difficult boards.

Crystal Quest — a 27-level match-3 adventure

Crystal Quest is a fantasy gem-matching game. Swap neighbouring gems to make matches of three or more, then use larger patterns to create special gems: line clears, colour clears, area blasts and seeker crystals. The campaign includes Guardian encounters, Crystal Resonance stages and a daily challenge.

Read the Crystal Quest match-3 browser game guide for the rules, then use the Crystal Quest strategy guide for move planning, blockers and Guardian encounters.

How to start playing

  1. Choose a game above and open its page. Both games run in a supported modern browser.
  2. In Arrow Out!, study each arrow's direction and tap only when its exit path is clear.
  3. In Crystal Quest, tap a gem and then a neighbouring gem, or drag between adjacent cells, to make a match.
  4. Check the game's own instructions for level objectives, controls and available features.

No account is required to start either game. Progress is stored in browser storage on the current device, so clearing browser data can remove a local save. Crystal Quest and Arrow Out! support offline play after their required game files have been cached; for the most reliable offline use, open each game while online first and follow its install or cache instructions.

Which game should you try first?

Choose Arrow Out! if you enjoy spatial reasoning, planning and finding a safe order to clear a crowded board. Choose Crystal Quest if you prefer matching gems, building special combinations and completing level objectives within a move limit. Both are free to start and designed for phone and desktop browsers.
